# S3 吃什么验收流程

验收目标（见 [05-roadmap.md](05-roadmap.md)）：**自己录入 20 家以上商家后，推荐结果合理。**

---

## 第 0 步：准备

确认本地数据库已启动并应用 S3 迁移（`20261121033000_s3_food_merchants_mood`）：

```bash
pnpm db:migrate
pnpm dev
```

检查 `apps/server/.env` 中 `MERCHANT_AUTO_APPROVE=true`（默认值，自用阶段提交商家直接上架）。

---

## 第 1 步：录入商家与实时查重

1. 打开「吃什么 → + 添店」，录入几家常去的食堂档口或南亭小店（填写名称、分类、位置、人均、步行分钟、口味标签、可选招牌菜）。
2. 再次点「+ 添店」，输入与已有商家相近的名称（如只输「煲仔饭」）。

**通过标准**：
- 提交后立即出现在「校区商家库」中。
- 输入相近名称约 0.3 秒后，下方弹出「发现相似商家，是否是这家？」，点「查看」可直接打开已有商家详情页。
- 在商家详情页可以继续补充/删除招牌菜品。
- 本校区商家少于 10 家时，推荐卡片下方显示冷启动引导提示「当前校区已收录 N 家店，满 10 家后推荐会更丰富」。

---

## 第 2 步：今日心情与口味偏好

1. 在「吃什么」顶部切换不同心情（开心 / 平静 / 疲惫 / 焦虑 / 低落 / 想犒劳自己），并写一句备注保存。
2. 点右上角「口味偏好」（或「我的 → 饮食偏好」），设置喜欢的口味、忌口（如「辣」）和每餐预算区间。

**通过标准**：
- 心情光球颜色与形态平滑过渡，返回首页「今天 → 今日心情」卡片同步显示当前心情与备注，且在首页可直接一键切换。
- 带忌口标签的商家不会再出现在推荐结果中；命中偏好标签的商家在推荐卡片上会高亮对应标签。

---

## 第 3 步：规则推荐与反馈

1. 切换「午饭推荐 / 晚饭推荐」，查看顶部天气与课表空档摘要条。
2. 对候选卡片依次测试「就吃这个」「换一个」「不想吃」，以及右上角「换一批」。

**通过标准**：
- 每次最多返回 3 个候选，且优先分散在不同品类（不出现三个都是粉面）。
- 推荐理由贴合当前天气、课表空档、心情或招牌菜。
- 点「就吃这个」后出现在「最近吃过」列表，且接下来 3 天内会降低该店权重。
- 点「换一个」或「换一批」不再重复出现本轮已看过的商家，全部看完后可点「重新看一遍」。
- 点「不想吃」后近期不再推荐该店。
- 饭点时段（11:00–13:00 / 17:00–19:00）打开「今天」首页，餐食推荐卡片自动上移到时间线下方。

---

## 第 4 步：管理后台（管理员）

1. 使用 `ADMIN_EMAILS` 中的管理员账号登录，进入「我的 → 商家管理 · 管理员」（路径 `/admin`）。
2. 按状态筛选（全部 / 待审核 / 已上架 / 已拒绝 / 已关店），尝试对某测试商家执行「标记关店」再「通过上架」。

**通过标准**：
- 非管理员账号看不到入口，直接访问 `/admin` 会自动跳回首页。
- 标记关店后，该商家立即从推荐和公开商家库中消失；重新「通过上架」后恢复可见。
