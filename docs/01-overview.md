# 01 产品概述

## 1. 产品定位

一个以「今天」为中心的校园生活助手。用户打开应用，第一屏就能看到：今天天气怎样、接下来上什么课、中午晚上吃什么、还有哪些事没做完。

- 主要用户：广东工业大学在校学生。只做广工，不考虑多学校，校区和作息表直接内置为配置数据。
- 主要终端：手机浏览器 / PWA → 后续原生壳 App；电脑端使用同一套 Web 应用的宽屏布局。
- 设计目标：功能上「打开即得」，视觉上有辨识度（玻璃态、动效、3D），但不能牺牲加载速度和可读性。

## 2. 典型使用场景

| 时间 | 场景 | 涉及功能 |
| --- | --- | --- |
| 07:30 | 起床打开应用，看到今天有雨、上午 3 节课，提示带伞 | 天气、课表 |
| 11:40 | 第 4 节下课前 10 分钟推送「午饭推荐：二饭三楼的煲仔饭，离教学楼 5 分钟」 | 推荐、提醒 |
| 14:00 | 收到「高数作业明天 23:59 截止，今晚 19:00–21:00 你没课」提醒 | 待办、课表 |
| 18:30 | 吃完饭给商家打 4 星并写评论，顺便看看本周榜单 | 评分榜单 |
| 22:00 | 在电脑上整理明天的待办 | 待办（Web 宽屏） |

## 4. 非功能需求

| 维度 | 指标 |
| --- | --- |
| 首屏性能 | 4G 网络中端安卓机 LCP < 2.5s；首屏 JS（gzip）< 200KB，3D 资源延迟加载 |
| 动画流畅度 | 中端机 ≥ 50fps，高端机 60fps；低端机自动降级 |
| 可用性 | 核心功能离线可读（PWA 缓存今日天气、课表、待办） |
| 提醒准确性 | 提醒发出误差 < 1 分钟 |
| 可访问性 | 玻璃卡片上文字对比度 ≥ 4.5:1；支持系统「减少动态效果」 |
| 安全与隐私 | HTTPS 全站；最小化收集位置信息（只存到区县级）；符合《个人信息保护法》 |
| 可维护性 | 一人开发维护：优先选托管服务和少量依赖，运维工作尽量自动化；后端模块化单体 |
