# GDUT Help 使用说明

> 面向广东工业大学同学的校园生活助手（天气、课表与课前提醒、待办、吃什么推荐、校园美食榜单）。
> 本文档前半部分可直接转发给参与内测的同学，后半部分为管理员与开发者日常运维手册。

---

## 第一部分：同学端使用指南（内测版）

### 1. 安装与登录

1. **安装 App**：下载并安装最新基线版安卓安装包（`GDUT Help v0.2.0` 及以上，首次安装允许「未知来源应用」）。
2. **注册账号**（首次使用）：
   - 打开 App，在登录页底部点击 **「注册账号」**。
   - 输入常用邮箱（支持广工邮箱、QQ 邮箱、163 等），点击获取验证码。
   - 到邮箱查收 6 位验证码（如果 1 分钟未收到，请检查「垃圾邮件 / 订阅邮件」文件夹）。
   - 输入验证码、昵称和登录密码（至少 8 位），提交即自动登录。
3. **日常登录**：
   - 支持 **「密码登录」**（推荐，最快）与 **「验证码登录」** 两种方式。
   - 忘记密码可点击 **「忘记密码」** 通过邮箱验证码重置。
   - 单个账号最多同时保持 10 台设备登录；在 **「我的 → 账号安全与数据」** 可随时修改密码、导出 JSON 备份、退出全部设备或注销账号。

> **如果内测服务器地址临时变更**：无需重新下载安装包！退出到登录页，点击最底部 **「服务器地址」**，粘贴新地址，先点 **「测试连通性」** 通过后点 **「保存并使用」** 即可。

---

### 2. 首次必做：设置你的校区

登录后进入右下角 **「我的」**，选择所在校区（默认 **大学城校区**，支持大学城 / 龙洞 / 东风路 / 番禺 / 揭阳）：

- **作息时间**：不同校区上课节次时间自动匹配。
- **实时天气**：首页温度、降雨带伞提醒与 3D 天空背景自动对应校区坐标。
- **吃什么 & 榜单**：优先推荐你所在校区及周边商家（如大学城已收录各饭堂、GOGO 新天地、南亭村美食等）。

---

### 3. 导入课表（4 种自助方式，无需等管理员）

点击底部 **「课表」→ 右上角「导入」**，按需任选一种：

1. **方式一：App 内一键读取教务系统（最推荐）**
   - 点击 **「从教务系统读取课表」**。
   - 在弹出的学校官方登录页输入你的统一身份认证账号密码登录（**密码仅在学校官方页面使用，不经过本应用服务器**）。
   - 登录成功后会自动读取当前学期全部课程，核对差异列表后点 **「确认导入」** 即可；首次导入还会自动校准学期第一周周一日期。
2. **方式二：输入 6 位同学分享码（最快 10 秒）**
   - 同班同学或室友在课表页点右上角 **「分享」**，会生成一个 6 位分享码（7 天内有效，仅含课程安排，不含个人隐私）。
   - 你在 **「导入」** 页输入分享码，预览课程后点 **「确认导入」** 即可完整复制。
3. **方式三：上传文件 / 粘贴数据（适合电脑端或已有日历）**
   - 支持粘贴或上传从教务系统抓包导出的 `.json`，或通用 `.ics` 日历文件。
4. **方式四：手动添加与微调**
   - 点课表页右上角 **「添加」** 可录入自定义课程；点击任意已导入的课程卡片可修改教室、老师、周次或颜色。

**课表小技巧**：
- 支持 **「按天」** / **「整周」** 两种视图切换。
- 按天视图中，左右滑动顶部日期条可快速切换上一周 / 下一周。

### 4. 日常功能一览

| 模块 | 核心用法 |
| --- | --- |
| **今天** | 顶部实时天气与带伞提示；若有 7 天内截止的 P1 紧急待办会自动显示倒计时胶囊；下方聚合今日时间线、下一节课、今日心情、吃什么快捷推荐与待办概览（午饭/晚饭时段自动上移餐食卡片）。 |
| **课表** | 查看每天/整周课程、正在上课高亮、一键分享课表给室友；在 **「我的 → 提醒设置」** 中可开启 **课前本地通知提醒**（默认提前 15 分钟）。 |
| **吃什么** | 根据当前餐段、天气、你设置的口味/忌口/预算与就餐场景（一人食/聚餐、赶时间/慢慢吃）智能推荐；支持「换一批」「就吃这家」「不想吃」，也可自行补充新商家。 |
| **待办** | 支持中文快捷输入（如输入「明天下午3点交高数作业 P1」自动解析时间与优先级）；支持每日/每周/每月重复待办与定时提醒；**断网时也能先记下，联网自动同步**。 |
| **榜单** | 查看本校区综合口碑榜、分类榜与近期热榜，支持给吃过的店写点评与点赞。 |
| **我的** | 修改昵称/校区、设置饮食偏好与忌口、配置课前/待办提醒、预览天气主题、调节画质、检查应用热更新、管理账号密码与导出个人数据。 |

### 5. 应用更新（在线热更新，无需反复发 APK）

- **自动静默更新**：每次发布页面、样式或功能优化后，App 启动时会自动在后台下载约 0.8 MB 的更新包，你切回桌面或下次重启 App 即可无感生效。
- **手动立即更新**：进入 **「我的 → 应用更新 · 热更新」**，点击 **「检查更新」**，发现新版本后会自动下载并立即刷新切换。
- **重装提示**：仅当更新涉及安卓底层原生权限或新原生插件时，提示「需要下载安装新版 APK」，平时均在线热更。

### 6. 同学常见问题

- **收不到邮箱验证码？**
  1. 确认邮箱地址拼写无误；
  2. 检查邮箱的「垃圾箱 / 广告邮件」；
  3. 同一邮箱 60 秒内仅可发送一次，请倒计时结束后重试。
- **旧手机感觉动画偏重？**
  进入 **「我的 → 显示设置」**，将 3D 天空画质调低或关闭动态背景，即可获得最高续航与流畅度。
- **提示连不上服务器？**
  内测阶段后端运行在开发者电脑上，如遇到维护或隧道换址，联系开发者获取最新状态或按第 1 节在登录页切换服务器地址。

## 第二部分：开发者 / 管理员运维说明

### 1. 本机内测环境日常启动（Windows）

需要保持 3 个后台进程运行（电脑不休眠即可让校内外同学随时访问）：

```powershell
# 1) 启动本地 PostgreSQL（Prisma dev）
pnpm --filter @gduthelp/server exec prisma dev --name gduthelp

# 2) 启动后端与前端开发服务（后端监听 http://127.0.0.1:3000/api/v1）
pnpm dev

# 3) 启动 Cloudflare HTTP/2 公网隧道（务必带 --protocol http2，延迟更低更稳）
& 'C:\Program Files (x86)\cloudflared\cloudflared.exe' tunnel --protocol http2 --url http://127.0.0.1:3000
```

> 启动后终端会输出 `https://xxxx.trycloudflare.com`。如果隧道重启导致域名变化：
> - **已有 App 的同学**：只需把新域名发群里，让大家在登录页底部「服务器地址」粘贴即可（无需重装 APK）。
> - **新打 APK**：更新 `apps/web/.env.android.local` 里的 `VITE_API_ORIGIN` 后再构建。

---

### 2. 日常发布前端热更新（推荐，800 KB 秒级推送）

只要本次修改**只涉及前端页面/样式/逻辑（或 `packages/shared`）**、没有新增原生 Capacitor 插件，直接运行一行命令即可发布热更新：

```powershell
pnpm ota:pack 0.2.1 "修复若干显示问题，优化吃什么推荐卡片"
```

脚本会自动完成：
1. 构建 `@gduthelp/shared` 与 android 模式的前端 `apps/web/dist`（注入 `VITE_APP_VERSION=0.2.1`）；
2. 将构建产物打包为 POSIX 路径标准 ZIP，输出到 `apps/server/ota-bundles/bundle-0.2.1.zip`；
3. 计算 SHA-256 并更新 `apps/server/ota-bundles/manifest.json`（后端接口实时读取，**无需重启 NestJS**）。

> **版本号规则**：每次发布递增语义化版本号（如 `0.2.0` → `0.2.1` → `0.2.2`）。若同时改了后端 API，确保本机后端已更新并重启即可。

---

### 3. 何时需要重新打包 APK & 打包步骤

仅在以下情况需要重打并分发新 APK：
- 新增/升级了 Capacitor 原生插件或修改了 `apps/web/android/` 原生代码；
- 想把新的默认公网地址（如正式云服务器域名）内置为默认配置。

打包步骤：
1. 如涉及原生外壳升级，将 `apps/web/android/app/build.gradle` 的 `versionCode` 和 `apps/web/src/lib/ota-updater.ts` 的 `NATIVE_APP_VERSION` 同步 +1（并同步 `versionName`）。
2. 确认 `apps/web/.env.android.local` 内容正确（此文件已被 `.gitignore` 忽略，不会入库）：
   ```env
   VITE_API_ORIGIN=https://你的最新公网域名
   VITE_APP_VERSION=0.2.0
   ```
3. 执行前端构建、Capacitor 同步与 Gradle 编译：
   ```powershell
   pnpm --filter @gduthelp/web build:android
   $env:JAVA_HOME = 'C:\Program Files\Microsoft\jdk-21.0.13.102-hotspot'
   $env:ANDROID_HOME = 'C:\Users\38512\AppData\Local\Android\Sdk'
   Set-Location apps\web\android
   .\gradlew.bat assembleDebug --no-daemon --max-workers=2
   ```
4. 成品位置：`apps/web/android/app/build/outputs/apk/debug/app-debug.apk`。

### 4. 管理员权限与内测门控配置

所有运行期密钥与开关位于 `apps/server/.env`（已被 `.gitignore` 忽略，**切勿提交到 Git**）：

| 配置项 | 说明 |
| --- | --- |
| `ADMIN_EMAILS` | 管理员邮箱列表（逗号分隔）。管理员登录后在 **「我的」** 中可见 **「商家管理 · 管理员」** 与 **「学期设置」**。 |
| `ALLOWED_EMAIL_DOMAINS` | 可选：限制只允许指定后缀注册（例如 `mail2.gdut.edu.cn,qq.com`）；留空则不限制。 |
| `INVITE_CODE` | 可选：设置内测邀请码；留空则允许自由注册。 |
| `MAIL_DRIVER` / `SMTP_*` | 邮件验证码发信配置（当前已配置 QQ 邮箱 SMTP 465 端口）。 |
| `CORS_ORIGINS` | 必须包含 `https://localhost`，供安卓 Capacitor App 跨域访问 API。 |
| `QWEATHER_API_HOST` / `KEY` | 可选：配置和风天气可获取更精准国内天气；留空时自动使用 Open-Meteo + MET Norway 备用源并带内存预热缓存。 |
