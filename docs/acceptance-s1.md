# S1 视觉原型验收流程

验收目标（见 [05-roadmap.md](05-roadmap.md)）：

1. 你自己的手机上，首页帧率 ≥ 50fps。
2. 低画质档位降级正常：没有 3D，玻璃不模糊，文字清楚。

下面的步骤按顺序做，大约 30 分钟。每项后面写了**通过标准**，最后有一张记录表，填好发给我即可。

---

## 第 0 步：在电脑上启动

### 0.1 确认数据库在运行

```bash
cd apps/server
pnpm exec prisma dev ls
```

`gduthelp` 一行显示 `running` 即可。如果是 `stopped`，执行 `pnpm exec prisma dev start gduthelp`。

### 0.2 选一种让手机访问的方式

| 方式 | 优点 | 限制 |
| --- | --- | --- |
| **A. 同一 Wi-Fi（推荐先用这个）** | 不用装软件 | 是 HTTP，**陀螺仪测不了**（iOS 和安卓浏览器都只在 HTTPS 下提供陀螺仪数据）。只在家里的 Wi-Fi 用，不要在校园网、公共 Wi-Fi 下开 |
| **B. Tailscale** | HTTPS，所有项目都能测 | 要装 Tailscale，登录时需要能访问 tailscale.com |

**方式 A：同一 Wi-Fi**

开两个终端，在项目根目录分别运行：

```bash
# 终端 1：后端
pnpm --filter @gduthelp/shared build && pnpm --filter @gduthelp/server dev

# 终端 2：前端，--host 让局域网内的设备能访问
pnpm --filter @gduthelp/web dev --host
```

终端 2 会打印一行 `Network: http://192.168.x.x:5173/`，手机连同一个 Wi-Fi，用浏览器打开这个地址。

打不开的话，多半是电脑防火墙拦了 5173 端口。Ubuntu 上执行 `sudo ufw allow 5173/tcp`，测完后用 `sudo ufw delete allow 5173/tcp` 删掉这条规则。

**方式 B：Tailscale**

```bash
curl -fsSL https://tailscale.com/install.sh | sh   # 安装
sudo tailscale up                                   # 按提示在浏览器里登录
```

1. 手机也装 Tailscale App，登录同一个账号。
2. 在 Tailscale 管理后台 → DNS 页面，开启 **MagicDNS** 和 **HTTPS Certificates**。
3. 电脑上运行 `pnpm dev`，然后执行 `tailscale serve --bg 5173`。
4. 用手机打开命令输出的 `https://<机器名>.<tailnet>.ts.net` 地址。

测完后执行 `tailscale serve reset` 关闭访问。

### 0.3 用手机登录

1. 输入任意邮箱，点「获取验证码」。
2. 在电脑的**后端终端**里找 `[开发] xxx 的验证码：123456`，把验证码输入手机。

**通过标准**：登录后进入「今天」页面，能看到天空背景。

---

## 第 1 步：确认自动检测的画质

1. 进入「我的」（「今天」页右上角的圆形头像）→「显示设置」。
2. 「画质」选「自动」。
3. 看下面「当前：」那一行，比如 `当前：高 · apple a15 gpu` 或 `当前：中 · adreno 650`。
4. 打开「显示帧率」，屏幕右下角会出现 `xx fps · 高` 字样的读数。

**记录**：当前档位，以及显示的 GPU 名称。

> 如果这一行写着「因帧率不足已降为…」，说明之前已经自动降过档。先点「重新检测」，再继续。

---

## 第 2 步：首页帧率（核心验收项）

方法：在「我的 → 主题预览」里选一种天气，回到「今天」页，**手不要碰屏幕**，静置 10 秒，记下右下角帧率稳定后的大致范围。

要测的天气：

| 天气 | 必测 / 选测 | 画面里应该有什么 |
| --- | --- | --- |
| 晴 | 必测 | 右上方太阳，缓慢旋转的光芒，少量白云飘过 |
| 雨 | 必测 | 斜落的雨丝、灰蓝色云层（粒子最多，压力最大） |
| 夜 | 必测 | 闪烁的星星、带暗斑的月亮、少量暗色云 |
| 雷 | 选测 | 暴雨，每隔几秒一次双闪，闪的时候云会变亮 |
| 多云 / 雪 / 雾 | 选测 | 大片云层 / 飘落的雪花 / 大而淡的雾状云 |

**先在「自动」档下测**。如果帧率低于 50：

1. 「画质」手动选「中」，再测一遍雨天。
2. 还是低于 50 的话，选「低」，确认至少能流畅使用。

> 说明：「自动」档下连续 3 秒低于 40fps 时会自动降一档，所以测试中途档位可能会变，以右下角显示的档位为准。手动选择的档位不会被自动降档改掉。

**通过标准**：「高」或「中」至少有一档，在晴、雨、夜三种天气下都能稳定 ≥ 50fps。

---

## 第 3 步：天气切换与页面切换

| 操作 | 通过标准 |
| --- | --- |
| 在「主题预览」里依次切换几种天气（特别是 夜→雨、雨→晴、晴→雷） | 背景颜色约 1 秒内平滑过渡，中途没有一下变亮或变暗的闪屏；太阳、云、雨等元素淡入淡出；右下角帧率不会在切换瞬间掉到 30 以下 |
| 选「雨」，切到「待办」页 | 卡片后面的雨**停住不动**（离开首页后 3D 冻结，省电） |
| 再切回「今天」 | 雨重新开始落下 |
| 底部标签栏从左往右、从右往左点 | 页面跟着往对应方向滑动，选中块平滑移动 |
| 首页上下滑动 | 滚动流畅，背景不跟着手指乱晃 |

---

## 第 4 步：低画质档位

「画质」选「低」，然后分别在「晴」和「夜」两种天气下检查：

| 检查点 | 通过标准 |
| --- | --- |
| 天空 | 只剩渐变色和柔和光斑，没有太阳、星星、雨等 3D 元素 |
| 卡片 | 不再透出背景的模糊效果，变成半透明纯色底；晴天偏白，夜里偏深 |
| 文字 | 所有卡片上的文字都清楚可读 |
| 底部标签栏 | 滚动时，后面卡片的文字不会透过来和标签文字叠在一起 |
| 帧率 | 接近屏幕刷新率（一般是 60，高刷屏 90/120） |

测完把画质改回「自动」。

---

## 第 5 步：陀螺仪视差（选测）

**只能用方式 B（Tailscale 的 https 地址）**，iPhone 和安卓都一样。用方式 A 的 http 地址打开开关，会提示「陀螺仪只能在 HTTPS 页面使用」，这是浏览器的限制，不是故障。

| 手机 | 怎么测 |
| --- | --- |
| iPhone | 打开「陀螺仪视差」开关，会弹出权限请求，选「允许」 |
| 安卓 | 打开开关即可，一般不会弹出请求。如果提示「没有收到陀螺仪数据」，检查 Chrome 的网站设置 → 动作传感器是否允许 |

回到首页（晴或夜），手机左右、前后倾斜。

**通过标准**：太阳/月亮和云会错开移动，有纵深感；手机放平不动时，画面也平稳不抖。

打开开关后会检测 1.5 秒内是否真的收到倾斜数据，失败时会显示具体原因。把提示文字、手机型号和浏览器告诉我。

---

## 第 6 步：系统「减少动态效果」（选测）

| 系统 | 开关位置 |
| --- | --- |
| iOS | 设置 → 辅助功能 → 动态效果 → 减弱动态效果 |
| 安卓 | 设置 → 无障碍 → 移除动画（不同品牌名称不同，也可能叫「关闭动画」） |

开启后刷新页面。

**通过标准**：天空是静止画面，但太阳、星星、月亮都在；雷雨天不闪；页面切换没有大幅滑动。

测完记得把系统设置改回来。

---

## 第 7 步：稳定性

| 操作 | 通过标准 |
| --- | --- |
| 首页停留 3 分钟 | 手机不明显发烫，帧率没有越来越低 |
| 切到其他 App 1 分钟，再切回来 | 天空正常显示，没有变成空白或纯色（检查切后台后 WebGL 能否恢复） |
| 横竖屏旋转（如果浏览器允许） | 太阳、月亮的位置随之调整，画面不拉伸变形 |
| 刷新页面 | 仍是登录状态，画质和主题设置都还在 |

---

## 第 8 步：电脑端（选测）

在电脑浏览器打开 <http://localhost:5173>：

| 检查点 | 通过标准 |
| --- | --- |
| 布局 | 窗口宽度 ≥ 1280px 时显示左侧玻璃侧边栏，没有底部标签栏 |
| 视差 | 首页移动鼠标，天空跟着轻微错位 |
| 帧率 | 打开帧率显示，晴、雨、夜三种天气都能稳定在 60 左右（或屏幕刷新率） |

## 结果怎么处理

| 情况 | 下一步 |
| --- | --- |
| 「高」或「中」在三种天气下都 ≥ 50fps，其他项通过 | S1 验收通过，开始 S2 |
| 只有雨天低于 50 | 我把雨的粒子数和雨丝尺寸调小，你再测雨天 |
| 三种天气都低于 50，但「低」档流畅 | 我降低中档的参数（分辨率、云团数），必要时改成默认用低档，再请你复测 |
| 某个画面显示异常、切后台回来变空白 | 把截图或录屏、手机型号、浏览器发给我，我修完后只复测这一项 |
