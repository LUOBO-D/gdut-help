# 安卓 App 本地提醒验收流程

验收目标：**锁屏、划掉 App、断网、电脑关机，待办提醒都能准点弹出。**

功能检查约 30 分钟。打包和安装步骤见 [DEVELOPMENT.md](DEVELOPMENT.md)「安卓 App（自用）」。

---

## 第 0 步：准备

1. 电脑上启动后端和前端：`pnpm --filter @gduthelp/server dev`、`pnpm --filter @gduthelp/web dev`。
2. `tailscale serve status` 能看到 `/` 和 `/api` 两条转发。
3. 手机打开 Tailscale 并连接（安卓同时只能开一个 VPN，先关掉代理 App）。
4. 手机设置 → 应用 → GDUT Help：
   - 耗电管理：「允许后台行为」
   - 打开「自启动」

## 第 1 步：登录

打开 App，用自己的邮箱登录。验证码在后端日志里（`MAIL_DRIVER=console` 时）或邮箱里。

- [ ] 能登录，进入今天页，天气和 3D 天空正常
- [ ] 划掉 App 再打开，仍是登录状态（不用重新输验证码）
- [ ] 关掉手机上的 Tailscale 再打开 App：能看到上次的数据，顶部提示离线；重新连上后恢复

## 第 2 步：权限

「我的 → 提醒设置」：

- [ ] 「通知权限」显示已允许（第一次点「去允许」，系统弹框选允许）
- [ ] 「闹钟和提醒」显示已允许
- [ ] 点「1 分钟后弹一条测试通知」，**锁屏**等待，1 分钟后弹出
- [ ] 点通知能打开 App

## 第 3 步：待办提醒

在 App 里新建 4 条待办，分别设 2、4、6、8 分钟后的「指定时间」提醒。回到「我的 → 提醒设置」，「已写入手机的提醒」应为 4 条。

| 场景 | 操作 | 结果 |
| --- | --- | --- |
| 锁屏 | 锁屏等第 1 条 | |
| 划掉 App | 从最近任务里划掉 App，等第 2 条 | |
| 断网 | 打开飞行模式，等第 3 条 | |
| 电脑关机 | 关掉电脑上的后端（Ctrl+C），等第 4 条 | |

- [ ] 4 条都准点弹出（误差 1 分钟内）
- [ ] 通知点开后进入待办页

## 第 4 步：同步

- [ ] 在 App 里把一条待办勾选完成，它的提醒不再弹出
- [ ] 在电脑浏览器上新建一条带提醒的待办，再打开一次手机 App，「已写入手机的提醒」数量加 1，到点弹出
- [ ] 重启手机，不打开 App，之前写入的提醒仍会弹出

## 已知限制

- 在电脑上新建或修改的待办，要打开一次 App 才会写进手机。
- 只写入未来 7 天、最多 64 条提醒；更远的在之后打开 App 时补上。
- 邮件提醒和站内通知仍由服务端发送。只用手机时可以在「提醒设置」里关掉邮件提醒，避免重复。
- 课程（上课前）提醒还没有做，目前只有待办提醒。
